# SoulLike Documentation

이 문서는 2년 전 언리얼 프로젝트를 AI와 함께 현대화하고 완성도를 높이는 과정을 기록하기 위한 공간이다.

목표는 단순한 설치 매뉴얼을 만드는 것이 아니라, 기존 프로젝트에 투입되었을 때 어떤 문제를 발견했고, AI를 어떻게 활용했으며, 어떤 근거로 구조를 개선했는지를 날짜별로 남기는 것이다.

## 문서 구조

- `work-log/`: 날짜별 작업 기록
- `architecture/`: 리팩터링 전후 코드 구조, 책임 분리, 런타임 흐름 기록
- `summaries/`: 프로젝트 목표, 마일스톤, 외부 공유용 요약
- `decisions/`: 별도로 남길 가치가 있는 기술적 의사결정

## 읽는 순서

1. `summaries/2026-06-04-modernization-roadmap.md`
2. `summaries/2026-06-04-execution-plan.md`
3. `architecture/2026-06-04-current-code-architecture.md`
4. `work-log/2026-06-04.md`

## 기록 원칙

- 작업 목표와 기존 문제를 먼저 적는다.
- AI를 어떻게 활용했는지 구체적으로 적는다.
- 구현 내용보다 검증 결과와 남은 위험을 반드시 남긴다.
- 막연한 표현보다 실제 변경점, 빌드 결과, 동기화 결과, 테스트 조건을 기록한다.
