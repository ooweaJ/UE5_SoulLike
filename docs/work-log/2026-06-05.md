# 2026-06-05 작업 기록

## 작업 목표

PIE 창 2개 대신 별도 프로세스로 리슨서버 1개와 클라이언트 1개를 실행해 AI/멀티플레이 동기화를 확인할 수 있는 테스트 방식을 준비한다.

## 기존 문제

- PIE 2인 테스트는 간단하지만, 에디터 내부 실행이라 백그라운드 프레임 저하나 창 포커스 문제로 화면 비교가 어려울 수 있다.
- Steam OSS 전환 전에는 NULL/직접 접속 기준으로 서버-클라이언트 동기화 문제를 먼저 분리해서 확인해야 한다.

## 구현/수정 내용

- `Scripts/LaunchNullListenTest.bat` 생성.
- 첫 번째 프로세스는 `/Game/_dev/Level/MainWorld?listen`으로 리슨서버를 실행한다.
- 두 번째 프로세스는 `127.0.0.1`로 로컬 리슨서버에 접속한다.
- 두 프로세스 모두 `UnrealEditor.exe -game` 방식으로 실행한다.
- Steam이 아니라 NULL/직접 접속 테스트가 되도록 `-nosteam` 옵션을 사용한다.

## 사용 방법

프로젝트 루트에서 다음 파일을 실행한다.

```bat
Scripts\LaunchNullListenTest.bat
```

실행 결과:

- `SoulLike Listen Server`: 리슨서버 창
- `SoulLike Client`: 로컬 클라이언트 창

## 검증 기준

- 두 창이 각각 실행되는지 확인한다.
- 클라이언트가 `127.0.0.1` 리슨서버에 접속되는지 확인한다.
- AI 타이밍 공격 몽타주 속도 변경이 서버/클라이언트 양쪽에서 같은 타이밍으로 보이는지 확인한다.

## 남은 작업

- 실제 bat 실행 후 서버/클라이언트 접속 여부 확인.
- 접속 실패 시 맵 직접 접속 방식과 GameInstance 세션 방식 중 어떤 경로가 필요한지 분리.
- NULL OSS PIE 2인 체크리스트와 별도 프로세스 체크리스트를 함께 정리.
